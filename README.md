# AI Worth It?

### GenAI ROI and Governance Analytics

Is workplace AI actually worth the investment?

This project uses PostgreSQL and SQL to analyze the cost, adoption, productivity, quality, employee trust, and governance risks of workplace AI tools. The final goal is to recommend whether each tool should be continued, improved, or discontinued.

## Business Questions

1. How much does each AI tool cost?
2. How many employees actively use each tool?
3. How much working time does AI save?
4. Does AI reduce work or create additional rework?
5. Which departments receive the most value?
6. Do employees trust the AI tools?
7. What privacy or compliance risks have occurred?
8. Which tools should the company continue, improve, or discontinue?

## Tools

- PostgreSQL
- SQL
- Python
- Tableau or Power BI
- Git and GitHub
